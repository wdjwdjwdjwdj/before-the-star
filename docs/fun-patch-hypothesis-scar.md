# 好玩补丁 · ①假设环 + ②可见偏一度（最小可验收）

叠在：V2 + 方案丙定稿之上。不扩图、不改充电秒数、不改胜负结构（链路 + cold≥1）。

## 目标体验（3–5 分钟）
- 每环有一个要验证的问题，不是瞎试设备。
- 一进站就能从场景看出「上回的账还在」。

---

## ① 假设环（开放问题驱动）

### 状态
- `memory.activeQuestionId`：当前开放问题；无则 null。
- 问题库（有序，按首次失败/观察解锁下一条；同时最多 1 条活跃）：

| id | 开局/触发后挂上的问句 | 验证条件（真实发生即「解答」） |
|---|---|---|
| q_gate | 锁住门的，是电还是别的？ | discover gate 或亲眼见失电门开 |
| q_cold | 断闸之后，冷从哪掉？ | 失电后 cold 下降至少 1，或储冷告警 |
| q_heat | 充电的热，谁在扛？ | discover heat/thermal，或过热一次 |
| q_residual | 时间归零后，什么没归零？ | 带着 residual>baseHeat 开局并读到余热反馈 |

### 规则
1. **新游戏**第一条：`q_gate`（或靠近任何设备前也可空，第一环 begin 后挂 q_gate）。
2. 验证成功：问句变已解事实（可进认知板）；`activeQuestionId` 清空；若库中下一条未解则**下环 begin** 再挂（本环不连环塞问）。
3. Tab：顶部固定「本环假设」= 当前问句；下方仍是已解事实 + 0–42s 简轴（丙已有则复用）。
4. **不**用问题锁机关；不会答题也能通关。
5. 解答奖励（轻）：累计解答 ≥2 视同 discoveries 进度，可计入丙的半就绪触发（与 discoveries≥3 OR wins≥1 并存，实现时：`solvedQuestions>=2` 也可触发捷径）。

### 验收
- 环1 Tab 可见一条问句；满足验证后变为已解。
- 不会因未答题而卡死。
- 3 分钟内至少完成「看见问题 → 用操作验证」一次。

## ② 可见偏一度（世界记得的表皮）

### 规则（只做表现 + 极少量表层状态，不新开资源系统）
1. **热痕**：当 `heat≥3.5` 或 `overheated` 本环曾为真 → `memory.scarHeat=true`；下环开局能源室：管路/反应堆偏红、散热翼微颤、热读数旁「账」字样，直到本环成功把 heat 压回 ≤baseHeat+0.2 并保持 2s，或通关后清除 scarHeat。
2. **霜痕**：当本环曾 `cold<1` 且尝试过启动被拒 → `memory.scarFrost=true`；下环开局休眠监视器结霜、保障读数偏蓝闪；本环若 C≥2 持续 3s 或通关则清。
3. **余热开局反馈**：`beginCycle` 若 residual>baseHeat，除现有广播外，强制播戏核句：`余热会留下。时间回到脉冲前，热量不回到脉冲前。` 并短震或灯闪 1 次（尊重减震设置）。
4. 痕迹**不**额外改 fe 公式（好玩补丁②不做⑤的策略扭曲）；只让人「看见环」。

### 验收
- 故意过热或拒发一次后，下一环不操作也能从画面区分「干净站」vs「带痕站」。
- 通关或按规则消痕后恢复。
- 无障碍：闪烁遵守设置里的强闪光开关。

---

## 明确不做（本补丁）
脉冲冲浪窗口战术；失败改最优解数值；卸余热新装置；扩房；新胜利条件。

## 试玩剧本（验收官）
1. 开局看 Tab 假设 → 乱试至门/断电 → 问题落地成事实。  
2. 故意休眠优先充到过热或冷拒发 → 看下环红管/霜纹 + 余热句。  
3. 再正常通一环 → 痕消或减弱，假设换下一条。  
墙钟目标：5 分钟内完成「验证一次假设 + 看见一次偏一度」。
