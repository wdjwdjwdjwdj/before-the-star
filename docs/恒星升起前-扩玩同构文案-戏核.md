> 约束：不改数值与机关结构；不揭机器人身份；主题咬合「环 Cycle」。  
> 承接：42s 辐射回环 · 四室 · 主电／电池／门锁 · 温控(能源↔休眠) · 储冷 · 余热 · 胜利＝休眠乘员安全撤离。

## 1) 一页前景提要

**设定前提**  
曙光站绕一颗会脉冲的星。环实验装置与脉冲每四十二秒同相：站体母线上的可寻址状态被拉回锚点——灯、闸、门锁、舱温读数「回来」。这不是死刑，是基础设施的自愈。代价写在别处：每一次「修好」，热量与负担被挤进仍连着休眠舱的回路；时间可以归零，**余热与你记住的事实不会**。

你以为自己是值守员。规程要你在回环里稳住能源与温控，让休眠乘员在窗口期被安全送出站体锚点之外。墙上手写标语仍在：世界会回来。你呢？——此刻读作：世界会复位；**乘员若还镀在会被复位的集合里，就会作为站的一部分回来，而不是离开。**

**玩家目标（表面）**  
在四十二秒回环中切换能源与休眠侧的温控／储冷，压住余热，打开撤离许可，完成休眠乘员的安全撤离。失败不是清档：余热与认知留下，下一环你带着「上次哪里把热推到了休眠侧」再跑——迭代，不是归零。

**世界记得什么**  
- 记得：**余热累积、你已发现的规程与因果、认知记录。**  
- 不记得（物理归零）：开关瞬时姿态、本环临时接线、未写入认知的汗与脚步。  
- 系统同构句：修好能源侧，往往在休眠／储冷侧制造代价；环要你看见这条闭合，并想再走一圈把它走偏一度。

## 2) 世界内文案 8 条（可替换广播／认知；设备口气）

1. **周期广播**  
   `曙光站，值守周期。距离辐射回环：四十二秒。休眠舱热预算请自行核对。`

2. **温控面板 · 能源优先时**  
   `温控：能源回路优先。休眠侧冷源抽取下降。注意余热迁移。`

3. **温控面板 · 休眠优先时**  
   `温控：休眠储冷优先。能源侧散热窗口缩短。母线负载上升。`

4. **储冷告警**  
   `储冷槽位低于安全裕度。回环后物理读数复位，槽内余热账不复位。`

5. **余热认知（发现句）**  
   `余热会留下。时间回到脉冲前，热量不回到脉冲前。`

6. **余热过高 · 站内提示**  
   `余热阈值越限。下一次回环将带着这笔账开始。建议：减少对休眠侧的热推送。`

7. **撤离拒绝 · 热／储冷不达标**  
   `撤离许可驳回：休眠乘员仍在站体锚点热耦合内。先把储冷与余热压到规程窗，再申请离站。`

8. **撤离拒绝 · 回环窗口冲突（或门／电未就绪）**  
   `撤离许可驳回：当前相位仍属回环采样窗。乘员若在此刻离舱，将被记入下一帧「站体状态」而非「离站状态」。`

（可选替换旧标语旁白，仍不揭身份）  
`世界会回来。乘员呢？`——仅作深层认知解锁句，开局仍用「你呢？」

## 3) 本次叙事明确不做

| 不做 | 理由 |
|------|------|
| 玩家＝机器人／非人口器身份反转 | 基线：表面值守员；身份暂不揭 |
| 双结局／多真结局分叉 | 本包只服务「撤离成功」主胜负；失败＝迭代再环 |
| 空夹子＝07＝自己 的完整自举接通 | 可留伏笔物件，本包不引爆，避免抢温控主循环 |
| 穿薄膜到「现在叶」奠基开局 | 与 V2「乘员撤离」胜利条件不同构；本包不写进主目标 |
| 用知识条数锁撤离 | 知识只解释因果，不开门 |
| 42 梗喜剧／漫游指南同人腔 | 42 只作周期与返照皮肤 |
| 把「保主体」改成新柱子名或换柱 | 柱子仍是：别让人（乘员）作为世界的一部分被召回；玩法表现是撤离与热账 |

## 给扩玩的咬合校对（一行）

时间归零 ↔ 余热／认知不归零；修好 A ↔ 代价出现在 B（能源↔休眠温控）；失败 ↔ 带着热账再入环；想再走一圈 ↔ 每环多懂一度「热被推到了哪」。
