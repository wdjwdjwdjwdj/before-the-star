# V2 基线（dist 反查）与方案丙缺口 — 给并行专员

## 游戏
《恒星升起前》OhMyGame/Three.js 短时循环解谜。验收：有趣、难度适中、3–5 分钟展出。主题「环 Cycle」。

## V2 已实现（勿当新需求重复发明）
- cycle=42, charge=4, launch=2, outageAt=17/1.8s
- 设备：断路器、电池、**循环温控分配器 thermal**、门、终端、三日志
- cooling: energy|cryo，**可无限切换**
- fe: baseHeat=2, baseCold=2, max=5, safeHeat=4, chargeHeat=2, chargeCold=2, recoveryPerSecond=0.2, coldSeconds=6
- 休眠优先充电：涨 H、蓄 C；能源优先：充电时可降温；H>safe 过热停充
- 失电：每 6s C−1；启动需 cold≥1 且原链路条件
- 余热：reset 记下 heat；下环 mc(residual)=max(2,min(4, residual-1))
- 认知新增 heat/thermal/cold/residual；胜利=休眠乘员安全撤离
- 交付物仅有 dist，实现须假设用户在 OhMyGame 源工程上改

## 方案丙仍要补的（本轮范围）
1. 温控**每环仅可切换 1 次**（含开局默认占用）
2. E 前**一句代价预告**（断闸/隔离/启动/拨温控）
3. 隔离副产物：能源优先时 C−1；休眠优先时隔离多耗 ~0.5s（或等价慢一步）
4. 储冷改为**短缓冲**：下调可囤收益或 cap，避免「先堆满再无脑跑链」
5. 余热：保留跨环，补**可选手动卸 1 点**（可选）；防死局
6. Tab：**开放问题 + 0–42s 简轴**（最小改）
7. 精通捷径：发现≥3 或通关≥1 后，半就绪（电池 50% 未隔离 **或** 记住上环模式，二选一）
8. 失败留痕：至少问题板/简短广播，物理仍清零
