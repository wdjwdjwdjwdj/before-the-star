## 补丁工单

### P1 温控每环最多切换 1 次
- 环状态 `thermalSwitchesLeft`；`beginCycle` 置 1。
- `interact('thermal')`：剩余>0 → 切换 `energy↔cryo` 并 −1，反馈用下列温控句；剩余=0 → 拒绝，提示「本环分配已锁定」，不切换。
- 新环刷新；暂停不消耗。

**验收**：同环第1次成功、第2次被拒且模式不变；新环可再拨1次。

### P2 E 前一句代价预告（不暂停，耗时=0）
- `nearest` 为 `breaker` / `battery`（将隔离时）/ `terminal` / `thermal` 时，在 E 上下文旁浮层 **一句**代价预告；远离消失。
- 随当前 `cooling`/`cold`/`heat`/余热变化；**不**停表。
- 预告要点（句式可短）：
  - 能源优先·将隔离 → 提示储冷将 −1
  - 休眠优先·将隔离 → 提示隔离将多耗约 0.5s
  - 断闸 / 启动 → 提示储冷/保障风险（与 cold≥1、失电衰减一致）
  - 拨温控 → 可预告将切到的模式副作用（用下方温控句缩略）

**验收**：靠近见一句、时间轴不停；能源优先靠近隔离可见扣 C 预告。

### P3 隔离副产物（做）
- 隔离成功分支：
  - `cooling==='energy'` → `cold = max(0, cold-1)` 瞬时
  - `cooling==='cryo'` → cold 不变；隔离完成 **+0.5s** 忙碌（完成时刻推迟或短锁），期间不能同帧连招断闸
- 不改充电秒数。

**验收**：能源隔离后 C−1；休眠隔离 +0.5s 且 C 不因隔离减少。

### P4 储冷短缓冲（用上表三处 fe）
- `chargeCold:1`、`coldSeconds:5`、`recoveryPerSecond:0.15`；其余 fe 不动。
- 目的：削弱「先堆满再无脑跑链」。

**验收**：断主电后约每 5s C−1；满 C 仍不能无视温控整段无脑通；`cold<1` 拒发。

### P5 卸余热
- **本版不做**。保留 V2 跨环自动 `mc` 每环 −1 逻辑即可。

### P6 Tab：开放问题 + 0–42s 简轴（最小）
- 认知屏改为：开放问题列表 + 一条 0–42s 简轴（主电 / 门锁 / 储冷或舱温趋势，最小）。
- 对应真实观察/`discover` 后问题变已解事实；未解保持问句。
- 暂停行为不变；认知不开门。

建议初始问题（可剪）：
- 「断电后谁在掉温？」→ 解后可挂储冷/余热相关认知
- 「温控拨向哪一侧时，另一侧付出什么？」

**验收**：Tab 见问题+简轴；观察后至少一条可解；物理清零后进度仍在。

### P7 精通半就绪（只做 A）
- 触发：`discoveries.length>=3` **或** `wins>=1`；下环开局可选「半就绪」。
- 半就绪：**出生仍在苏醒舱**；`charge=0.5`；`isolated=false`；主电默认开（不断电）；温控仍默认 energy 且 switchesLeft=1。
- 禁止：预充满、预隔离、预断电、记住上环模式（B 不做）。

**验收**：未触发无入口；触发后可选；仍须充至满→隔离→断电→启动。

### P8 失败留痕
- 超时/自然 `reset`：物理清零；保留问题进度、已解事实、捷径进度；余热按 V2 `mc` 继承。
- 保障不足拒发或储冷告警时：问题板高亮/新增 **或** 短广播（用下文案 4/7）；非全盘惩罚清零观感。

**验收**：失败再开环物理新开，问题/广播痕迹仍在。

## 嵌入文案（戏核 · 直接用）

周期广播（`beginCycle`）：  
`曙光站，值守周期。距离辐射回环：四十二秒。休眠舱热预算请自行核对。`

温控切到能源优先：  
`温控：能源回路优先。休眠侧冷源抽取下降。注意余热迁移。`

温控切到休眠优先：  
`温控：休眠储冷优先。能源侧散热窗口缩短。母线负载上升。`

储冷告警：  
`储冷槽位低于安全裕度。回环后物理读数复位，槽内余热账不复位。`

余热认知（发现句）：  
`余热会留下。时间回到脉冲前，热量不回到脉冲前。`

余热过高提示：  
`余热阈值越限。下一次回环将带着这笔账开始。建议：减少对休眠侧的热推送。`

撤离驳回 · 热/储冷不达标：  
`撤离许可驳回：休眠乘员仍在站体锚点热耦合内。先把储冷与余热压到规程窗，再申请离站。`

撤离驳回 · 门/电未就绪或窗口冲突：  
`撤离许可驳回：当前相位仍属回环采样窗。乘员若在此刻离舱，将被记入下一帧「站体状态」而非「离站状态」。`

## 总验收路径（试玩）
1. **环1** 默认能源优先跑经典链：E 前见隔离扣 C 预告；隔离后 C−1；通关或 `cold<1` 拒发均留问题/广播痕迹。
2. **环2** 拨一次休眠优先：见温控句与 H 压力；同环再拨被拒；余热仅靠 V2 自动衰减，无手动卸热。
3. **环3**（discoveries≥3 或已通关）：半就绪 50% 电未隔离，仍走满充→隔离→断电→启动，约 30s 内可再通。
4. **回归**：充电仍 4s、发射 2s、地图未扩、暂停不走时、保障线 cold≥1、无卸余热装置。

## 自动化应测
- 同环二次 thermal 被拒
- energy 隔离 C−1；cryo 隔离 +0.5s 且 C 不因隔离减
- `coldSeconds===5` 失电衰减；`chargeCold===1`；`recoveryPerSecond===0.15`
- `cold<1` 拒发；发射中途 cold 掉线不得误胜
- 过热禁充；新环或改模式（若仍有次数）可恢复
- 无手动卸余热入口；`mc` 行为与 V2 一致
- 半就绪仅 A：50% 未隔离，不跳过隔离/断电
- Tab 问题可解；失败留痕保留
