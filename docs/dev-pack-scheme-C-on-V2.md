# 《恒星升起前》开发任务包 · 方案丙叠 V2（扩玩汇总）

**给谁**：OhMyGame / 实现方  
**基线**：当前 V2（已有温控·储冷·余热·42s·休眠撤离）  
**目标**：3–5 分钟展出「保机伤人 vs 保人慢链」；难度适中；贴「环」

---

## A. 扩玩裁定（终值）

| 项 | V2 | 定稿 |
|---|---|---|
| 温控切换 | ∞ | **每环 1 次**；默认能源优先不预扣；拨一次扣一次 |
| `chargeCold` | 2 | **1** |
| `coldSeconds` | 6 | **5**（因保留隔离扣冷） |
| `recoveryPerSecond` | 0.2 | **0.15** |
| 其余 fe / cycle42 / charge4 / launch2 / 余热 `max(2,min(4,r-1))` | — | **不动** |
| 隔离副产物 | 无 | 能源优先隔离 **C−1**；休眠优先隔离 **+0.5s** |
| 卸余热交互 | — | **本版不做** |
| 精通捷径 | 无 | **电池 50% 未隔离**（discoveries≥3 或 wins≥1） |
| 预告 | 无 | 一句浮层，**耗时 0** |
| 保障 | cold≥1 | **保持** |

单环预期：能源 15–17s · 休眠 16–19s · 余热开局 17–21s；含一次失败墙钟 3–5 分钟。

---

## B. 世界观咬合（戏核，可替换文案）

前景一句：时间归零；余热与认知不归零；修好能源往往把热账挤向休眠；失败＝带着热账再入环。

可用句：
- 广播：`曙光站，值守周期。距离辐射回环：四十二秒。休眠舱热预算请自行核对。`
- 能源优先：`温控：能源回路优先。休眠侧冷源抽取下降。注意余热迁移。`
- 休眠优先：`温控：休眠储冷优先。能源侧散热窗口缩短。母线负载上升。`
- 储冷告警：`储冷槽位低于安全裕度。回环后物理读数复位，槽内余热账不复位。`
- 余热认知：`余热会留下。时间回到脉冲前，热量不回到脉冲前。`
- 撤离驳回·热：`撤离许可驳回：休眠乘员仍在站体锚点热耦合内。先把储冷与余热压到规程窗，再申请离站。`

本次不做：身份反转、双结局、知识锁门。

## C. 实现补丁清单（相对 V2）

1. **P1** 温控每环 1 次  
2. **P2** E 前代价预告（断路器/隔离/终端/温控）  
3. **P3** 隔离副产物（上表）  
4. **P4** `chargeCold=1`，`coldSeconds=5`，`recoveryPerSecond=0.15`  
5. **P6** Tab：开放问题 + 0–42s 简轴（最小）  
6. **P7** 半就绪捷径 A  
7. **P8** 失败留痕（问题板/广播；物理仍清零，余热按 V2）

**勿动**：充电秒数、地图、滑条、扩房、身份、胜负结构（链路+cold≥1）、认知锁机关。

## D. 试玩验收

1. 环1 默认能源：见隔离预告与 C−1；通或拒都留痕迹  
2. 环2 切休眠一次：H 压力；第二次拨温控被拒  
3. 达触发后半就绪：电池 50% 未隔离，仍须隔离+断电  
4. 暂停不走时；3–5 分钟内能对比两策略
