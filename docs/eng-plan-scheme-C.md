## P2 并行面（一名一事）
1. **环节奏**：只压 H/C/R/时长/切换次数，保证 3–5 分钟展出与难度适中。
2. **戏核**：只做世界观/文案与规则同构（环、代价、休眠撤离），不改规则数值。
3. **实装词**：只把已定规则翻成 OhMyGame 可执行提示词，不发明新玩法。
