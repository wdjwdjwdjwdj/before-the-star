# 方案丙 · 最小可验收规则（展会叠）

目标：3–5 分钟展出「有环 + 有策略」；难度适中；不扩地图、不改充电、不做身份反转。

## 0. 保留（V0 不可破）
- 四室布局与安全门：有电锁闭、失电释放。
- 链路：主电开 → 电池充满 → 隔离 → 断主电 → 穿门 → 启动撤离。
- 未隔离电池断电泄放；熟悉后仍须能单环通关。
- 认知由真实观察触发；不得用认知条目当机关解锁条件。

## 1. 新状态（仅这些）
| 名 | 初值 | 规则 |
|---|---:|---|
| 温控模式 | 能源优先 | 二元：能源优先 / 休眠优先；**每环可切换 1 次**（含开局那次算一次） |
| 热负荷 H | 2（上限 4） | 能源优先充电时 H 增速低；休眠优先充电时 H 增速高；H≥4 过热保护→禁止充电直至改模式或环重置 |
| 休眠储冷 C | 2（上限 3） | 短缓冲：休眠优先充电时 C↑；断主电后 C 随时间↓；**不可靠囤满再无脑跑链**（满 C 也撑不住整段无视温控） |
| 余热 R | 0（上限 2） | 本环若出现过热或「保机伤人」硬断闸，下环开局 R+1（封顶 2）；靠近散热口 E 可卸 1 点（耗时短） |
| 撤离可行 | 由条件算 | 见胜负 |

数值单位为设计单位，非真实物理。循环时长统一 **42 秒**。

## 2. 新/改动词
1. **拨温控**（维护室新装置）：切换二元模式；环内第 2 次起拒绝并提示「本环分配已锁定」。
2. **E 前预告**：靠近断路器/电池隔离/启动终端时，浮层一句代价（例：「断闸 → 储冷 −2」「休眠优先 → 热负荷↑」）。不暂停时间。
3. **卸余热**（可选短交互）：仅当 R>0。
4. **认知板**：由事实清单改为 **开放问题 + 0–42s 简轴**（主电/门锁/舱温趋势）；问题在观察后变为已解事实。
5. **捷径（精通）**：累计发现 ≥3 条或通关 ≥1 次后，下环开局可选「半就绪」：出生仍在苏醒舱，但电池已 50% 未隔离 **或** 温控默认记住上环最后模式（二选一，只开一个）。**不预充满、不预隔离、不断电。**

## 3. 互咬（必须每环可见 A↑B↓）
- **能源优先**：充电正常；休眠侧灯光变冷；断主电后 C 掉更快。
- **休眠优先**：C 易涨；充电时 H 涨快，易触过热；过热则充电中断（原链路变慢）。
- **抽冷副产物**：执行「隔离」时，若模式=能源优先，C−1（管网抽冷保机）；若已是休眠优先，则不抽 C，但隔离动画多 0.5s（保人慢一步）。
- **胜负条**：HUD 一条「休眠保障」= f(C, 主电是否断、是否过热)；启动时若保障不足 → 拒绝并发掘对应认知。

## 4. 胜负
**成功**：主网断开 ∧ 电池满且隔离 ∧ 启动 2s 内保障始终达标 ∧ 42s 内完成。  
**自然失败**：超时回环；R 按规则继承；物理清零；问题板/已解事实/捷径进度保留。  
**硬失败反馈**：保障不足拒绝启动 ≠ 死局；下环可改模式或先卸余热。

## 5. 明确不做
改充电速度/多充电模式；滑条温控；扩建房间；气闸/姿态/离站飞行；无限余热；程序化地图；身份反转/双结局。

## 6. 三分钟试玩剧本（验收用）
1. 环1：默认能源优先，按 V0 链路跑；隔离时见 C 掉/预告；断闸见保障条降；若仍通关→记「经典解」。若保障不足失败→问题板出现「断电后谁在掉温？」。
2. 环2：切换休眠优先再跑；看见 H 涨/可能过热；或带着 R 开局卸一点再跑。
3. 环3（若有捷径）：半就绪开局，30s 内用另一策略通关。  
**通过标准**：5 分钟内玩家至少做过一次「保机伤人」或「保人慢链」，并理解余热/问题板不是惩罚清零。

## 7. 自动化应测（给实现方，非我代写代码）
- V0 经典链在能源优先 + 初始 H/C 下仍可通。
- 休眠优先路径可通且 H 更高。
- 环内第二次拨温控被拒。
- 过热中断充电；改模式后可恢复。
- 断主电后 C 下降；C 不足拒绝启动；发射中 C 耗尽不得误胜。
- R 上限 2；卸余热 −1；主动重置不叠异常 R。
- 捷径不跳过隔离/断电。
- 暂停不走时。
